# 46회차 체크포인트 01 — 중간 기록

## 아크 개요
"다시 구해주는 사람" — 물약 상점을 열려면 약초학 도구 숙련자가 필요하다는 것이 드러나, 핏빛숲의 은둔 드루이드 이드라를 영입하기로 한다. 다만 이드라는 심목과 결속돼 있어 그냥 데려올 수 없다 — 결속을 어떻게 처리할지가 아크의 핵심이었다. 완전 은폐 노선으로 진행, 이드라 정식 합류로 아크 완료.

## 진행 순서 (여기까지)

1. **카를렌 창고**: 물약을 만들 사람이 없다는 것이 드러남. 베릭스가 핏빛숲의 이드라를 떠올림. 네리는 몇 회차 전 이미 새벽문에서 부모님을 뵌 상태라 카를렌에 남고, 베릭스·이자벨이 가시울 마을·핏빛숲으로 출발.
2. **가시울 마을**: 이자벨이 먼저 도착해 홀트(신설 NPC, 촌장)에게 베릭스가 이드라를 찾는다는 말을 전함. 다리아(재등장, HP 스냅샷 정정)와 이자벨이 Panache(자연20)로 약재 정기 거래 성사(선금 15gp, 이후 카를렌 직접 납품으로 확장).
3. **핏빛숲 재회**: 베릭스가 이드라와 재회, 하룻밤을 보냄. 이드라가 깊이 잠든 사이 몸을 빼(은신 20) 심목에 직접 접촉 — 「숲을 갉아먹던 것의 파편」으로 오염을 되돌림(clock_blight 0→1).
4. **가시울 마을 복귀·대기**: 다리아와도 재회, 거래 조건 확장(카를렌 직접 납품, 사냥 결과물 포함). 사흘 대기 중 clock_blight 자동 진행으로 4/4(가득 참) — 심목 급성 위기 발생.
5. **위기 개입**: 마을에 위급 소식이 닿아 베릭스·이자벨·다리아가 심목으로 급히 복귀. 이드라가 심목에 손이 붙들려 위험한 상태. 베릭스가 "내가 해보겠다"며 자리를 바꿔(연기 29) 직접 파편으로 심목의 힘을 흡수 — 실제로는 나무를 살리지 않고 죽게 두면서 구하는 척 연기함. 이드라의 급성 위기만 해소.
6. **기만·위로**: "나무가 마지막으로 씨앗을 넘겨줬다"는 이야기로 이드라를 기만(24) — 위로가 됨(clock_idra_doubt 2→1). 설득(29)으로 오늘은 심목과 홀로 시간을 보내게 하고, 이후 늘 곁에 있겠다고 약속.
7. **다리아와의 밤**: 다리아와 재회해 관계 심화. 다리아는 베릭스가 맨손으로 심목에 개입하는 것을 직접 목격 — 정체는 모르나 놀라움이 남음.
8. **이자벨에게 전말 공개**: 카를렌 귀환길, 베릭스가 이자벨에게 심목 오염이 자연 재발이 아니라 자신이 되돌린 것임을 전부 밝힘. 심목의 힘을 실제로 흡수했다는 것도 확인 — 새 특성 `feat_heartwood_remnant_s46`(식물과의 대화, 1일 1회, 무소모) 신설. 회상 장면으로 흡수 직후 심목과의 교감을 묘사.
9. **이드라 정식 합류**: 심목이 완전히 죽은 뒤 이드라가 카를렌 창고로 찾아와 합류. `state/chars/idra.json`으로 이동, HP 90→38(심목 결속 소멸), susp 1(clock_idra_doubt 이관). 베스퍼를 조제 보조로 소개(위치 정정 — 새벽문 아닌 카를렌으로 이미 이동해 있었음). 네리는 재료 수급, 리브는 베릭스와 사업 확장 업무 배정.
