# 소설화 문체 지침

00~40회차 정식 소설화 파일에서 뽑아낸 규칙입니다. 새 회차를 소설화할 때 이 문서와 해당 회차의 체크포인트(`archive/sessions/_checkpoints/S{회차}/`)만 있으면 됩니다.

## 파일

```
경로   archive/sessions/claude_{회차}회차_{제목}_베릭스_{YYYYMMDD}.md
제목   한 줄짜리 명사구 (예: 검은 씨앗 / 돌아갈 길 / 마지막 조각)
```

첫 두 줄은 고정 형식입니다.

```markdown
# 마지막 조각

> 40회차 · 그림자 없는 벌판
```

인용부호 줄에는 `회차 · 그 회차의 무대`를 적습니다.

## 분량과 구성

- 본문 1만~2만 자. 40회차 10,701자 / 38회차 13,074자 / 39회차 20,039자가 실제 값입니다.
- 소제목(`##`)은 **필요할 때만** 씁니다. 장소가 여러 번 바뀌는 회차는 붙이고(38회차 9개), 한 장소에서 이어지면 붙이지 않습니다(39·40회차 1개).

## 반드시 빼는 것

**다이스·수치·메뉴는 한 글자도 넣지 않습니다.** 기존 세 회차에서 `1d20`·`vs AC`·`판정`·`선택지` 출현 횟수는 **0건**입니다.

- 주사위 눈, 명중/피해 계산, HP 수치, 슬롯 잔량
- 번호 선택지, "무엇을 하시겠습니까" 같은 진행 안내
- GM의 메타 설명, 규칙 논의, 패치 안내

판정 결과는 **사건으로만** 씁니다 — "설득에 성공했다"가 아니라 그 사람이 무엇을 말하고 어떻게 표정이 바뀌었는지로 씁니다.

## 문체

- 인게임 서술은 **문어체 평서형("~했다")**. 1회차부터 이어온 형식이라 바꾸지 않습니다.
- 대사는 큰따옴표. 대사 뒤에 행동·표정·속내를 붙여 누가 말했는지 드러냅니다.
- 말줄임표로 시작하는 대사(`"…또, 당신이네요."`)는 인물의 망설임을 나타내는 기존 관습입니다.
- **인물의 말투는 지어내지 않습니다.** 각 캐릭터 파일(`state/chars/{id}.json`, `state/npcs/{id}.json`)의 `voice` 필드를 그대로 따릅니다.
- 외모가 등록된 인물은 이름으로만 부르고 외모를 다시 서술하지 않습니다.
- 한자 글자를 쓰지 않습니다(한자어의 한글 표기는 무방).

## 내용 원칙

- **체크포인트에 있는 사건만** 씁니다. 없던 장면·인물·대사를 새로 만들지 않습니다. 빈 곳은 채우지 말고 넘깁니다.
- 체크포인트에 기록된 플레이어의 실제 대사는 그대로 살립니다.
- 사건의 순서는 체크포인트를 따르되, 같은 장소에서 이어진 일은 한 흐름으로 묶어도 됩니다.
- 베릭스의 숨겨진 본성은 **서술자가 설명하지 않습니다.** 행동과 대사로만 드러나게 두고, 동료가 눈치채지 못한 것은 눈치채지 못한 채로 씁니다.
- 회차 안에서 벌어진 절차상 사고(GM의 규칙 위반과 정정 등)는 소설화에 넣지 않습니다.

## 재료 우선순위

1. `archive/sessions/_checkpoints/S{회차}/cp00.md` — 그 회차 최종 통합본
2. `cp01, cp02…` — 통합본이 압축한 세부(대사 원문이 여기 남아 있습니다)
3. `state/chars/*`·`state/npcs/*` — 인물의 말투·관계·아는 것
4. `archive/campaign_summary.md` — 앞 회차와의 연결
